# Earth texture

Put an equirectangular (2:1) Earth image here as **`earth.jpg`** (or
`earth.png`). The "Copy Earth texture" build phase copies it into the app;
without it the app shows a plain placeholder globe.

A good public-domain source is NASA Visible Earth's *Blue Marble*
(e.g. `land_shallow_topo_2048.jpg`, 2048 × 1024). Longitude −180° must be
at the left edge and the North Pole at the top — the standard layout.
